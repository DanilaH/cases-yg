# Competitive reference notes

Purpose: extract cheap, high-leverage retention primitives without copying the production burden of mature case simulators or full idle economies.

These notes are directional; live competitor features can change. Current product decisions live in `DECISIONS.md` / `GAMEPLAY_SYSTEMS.md` and override earlier reference ideas.

---

## Key references / lessons

### Сквиш Мистери Дамплинги: Открой Пельмень

Simple opener → rarity → collection reference.

Lesson: low-input mystery reveal can work as a skeleton, but theme/presentation carry much of the value.

### Сундук Удачи: пиксельный лут-симулятор

Observed research set included many items/rarities, luck meter, duplicate crafting, biomes, dailies, ads and leaderboard.

Useful transformation:

> **Luck/pity → SIGNAL**

The larger lesson is that duplicates need to feel productive. Lite V2 now solves that cheaply through automatic recycle:

> **duplicate → small CHIPS rebate + one Signal segment**

The earlier Tech Parts / Mod Bench idea is parked. It should not return merely because competitors have crafting; only revisit it if a larger real catalog exposes a specific duplicate sink/problem that CHIPS + Signal do not solve.

Do not copy seven rarity tiers/biomes or the feature-count arms race.

### Самодельные боксы: распаковка

Secret-compartment inspiration became **Hidden Pocket**: a cheap automatic post-reveal surprise rather than another manipulation mechanic.

Hidden Pocket remains a strong jackpot-like second beat. Lite V2 gives Charged a higher Hidden Pocket profile, while exact odds remain tuning values.

### Reference chest/coin loop

The useful pattern from the game we are currently taking loop inspiration from is not its exact economy but the structure:

> **small/free opening → immediate currency/progress → save toward a more valuable opening → repeat**

Our low-scope transformation is:

> **Basic Pouch → collectible + CHIPS → Charged Pouch**

We intentionally avoid copying timed free chests, energy, offline production or a large shop in Lite V2.

### Mature case-opener products

Useful reminders:

- repeated-open friction eventually creates demand for faster reveal;
- upgrades/contracts/economies can create retention but explode scope;
- broad catalogs need some form of pool/targeting control;
- a premium-feeling opening must be materially different, not just relabeled.

Our transformation:

- Quick Reveal remains a later response to demonstrated repetition friction;
- content growth is handled first by themed **Drops / loot pools**;
- family-targeted acquisition remains parked until Drop-level completion actually becomes frustrating;
- Charged must have visibly better rarity/Hidden Pocket profile and reward presentation.

### Mature external Case Opener-style products

Use as an idea warehouse, not a scope model.

Avoid turning the product into a simulated-gambling ecosystem with markets, crash/double/jackpot, giant minigame stacks or 3D inventory complexity.

# Current synthesis

## Gameplay Loop Lite V2 — next product pass

Include:

- existing tactile pouch opener/reveal;
- four-rarity collectible ladder;
- Hidden Pocket;
- Shelf + Library;
- one global CHIPS wallet;
- CHIPS on every Basic opening;
- duplicate auto-recycle → CHIPS + Signal;
- simplified `4 duplicates → next eligible standard collectible NEW` Signal rule, with Basic never bypassing its Legendary gate;
- one Charged Pouch bought with CHIPS;
- better Charged rarity/Hidden Pocket profile;
- Drop/loot-pool architecture hidden behind the single current Drop;
- Yandex/storage/analytics/ad boundaries already present.

Explicitly exclude from Lite:

- timed pouch charges/energy;
- offline income;
- passive collection production;
- Tech Parts / Mod Bench;
- Overcharge;
- Archive levels;
- upgrade trees;
- store scene;
- multiple spendable currencies;
- multiple standard collectible drops per pouch;
- Daily Spotlight/shelf evolution;
- large retention meta.

## Content/release expansion

Primary expansion lever remains **more desirable gadget families** using the repeatable art pipeline, grouped into themed Drops rather than one global mega-pool.

Only after Lite V2 + real Yandex DRAFT validation, reconsider additional systems if the real larger catalog demonstrates a specific need.

# Anti-patterns

Do not compete primarily on:

- raw system count;
- rarity-label count;
- worlds/biomes;
- betting framing;
- markets/trading;
- minigame count;
- 3D complexity;
- idle-system count.

Compete on:

- Y2K object desirability;
- collectible art consistency;
- fast satisfying opening;
- readable rarity/material escalation;
- every opening producing visible progress;
- duplicates feeling useful rather than dead;
- clear short goal toward Charged;
- strong visible collection;
- cheap surprise/chase mechanics;
- enough content variety without bloating the gameplay systems.
